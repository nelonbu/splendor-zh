# 自备贵族图片放置处

请将两张图片直接放在本目录，文件名严格使用：

- `N-06.png`（当前文件为 `N-06.PNG`）
- `N-07.png`（当前文件为 `N-07.PNG`）

建议规格：PNG、正方形、1024 × 1024 像素、RGB 或 RGBA。至少保持 512 × 512 像素，以免游戏内缩放模糊。人物或主要图案尽量放在画面中央，并给边缘留少量裁切空间。

图片只提供贵族背景画面；不要把分数、宝石要求、贵族 ID 或中文说明预先画进图片。正式界面会从主项目原有数据绘制这些信息。文件名仅用于建立展示映射，不改变贵族规则。

脚本按贵族 ID 对文件名作不区分大小写的匹配，并保留实际文件名。现有两张图分别为 849 × 849 与 900 × 900，已通过 PNG、尺寸和 SHA-256 检查。正式游戏使用 `public/custom-nobles/` 中的校验副本；`npm run assets:check` 对照项目内清单验证该副本，不依赖 PyGem 参考目录。
