# 阶段 4：双人同机界面文案与术语

范围按 `src/App.tsx` 的正式入口确定：开局页、玩法说明、棋盘、发展卡和贵族、宝石供应、两位玩家区域、行动提示、弃置弹窗、贵族选择弹窗、结算页，以及开发用素材测试局。静态文案、动态提示和无障碍标签集中于 `src/i18n/zhCN.ts`，无需新增国际化依赖。浏览器标题及语言标签在 HTML 入口。

| 概念 | 简体中文显示 | 说明 |
| --- | --- | --- |
| Splendor | 璀璨宝石 | 仅显示名，不改包名和文件名 |
| development card / tier | 发展卡 / 一级、二级、三级牌堆 | 卡牌数值仍取主项目数据 |
| noble tile | 贵族 | 要求与声望仍取主项目数据 |
| gem token / gold | 宝石筹码 / 黄金 | 黑色宝石虽为棕色美术，名称仍为“黑色” |
| card bonus | 永久加成 | 指已购买发展卡提供的减费能力 |
| prestige points | 声望点 | 紧凑牌面只显示数字，提示中写“点声望” |
| take / buy / reserve / discard | 拿取 / 购买 / 预留 / 弃置 | 与原动作状态对应，不参与规则判断 |
| Player 1 / Player 2 | 玩家一 / 玩家二 | 仅作空白档案的表单默认值；已保存或用户输入的名字原样保留 |

文案盘点：

- 开局：游戏标题、双人同机、玩法说明、姓名输入的默认值/占位符/无障碍标签、开始游戏、退出对局。
- 棋盘：当前玩家、弃置及贵族待办、最后一轮、贵族标题、三个等级牌堆与剩余数、购买/预留按钮、宝石供应和拿取确认/取消。
- 玩家区域：声望、宝石数量、永久加成、已购买/已预留数量、预留卡购买、上一步的四类行动（包括盲预留与零费用卡）。
- 弹窗：弃置数量/撤销/确认、贵族到访/选择与键盘可操作标签、玩法全部七个章节及插图说明。
- 结算：胜者、声望、再玩一局；保留但当前入口不可到达的 AI 对局结算按钮也已显示中文，模型名保持原值。
- 素材测试局：横幅及浏览器标题已中文化。规则弹窗原有两张 PNG 内嵌英文标签，现改为复用本项目宝石图标和代表性发展卡牌面，避免图片内英文无法翻译。

遗漏清单：按正式双人同机入口做源码扫描、组件测试和浏览器检查后，**未发现可到达界面的英文文案遗漏**。未翻译的技术名称包括内部卡/贵族 ID、`white/blue/green/red/black/gold` 颜色枚举、动作和状态字段、事件名、资源路径/文件名、包名、对局记录 JSON 文件名、AI 模型/提供商标识；这些不作为中文显示名称，也不用于美术映射之外的规则判断。

`AiReasoningPanel`、`OnlineLobby`、`PasswordGate`、`SettingsModal`、`ConnectionBanner` 仍在源码但没有从正式 `App` 双人同机入口挂载。其英语文本属于明确保留的非本地模式模块，不在本阶段交付范围。若未来恢复对应入口，需要另起阶段审计其文案与协议。开发控制台日志亦不属于游戏画面。

待进一步验证：内嵌浏览器宽约 521px，原有棋盘固定布局会横向超出视口；本阶段只调整中文长文案换行、规则示例换行与字体候选，不改整体棋盘布局。完整双人终局和 Windows 可执行入口内嵌资源仍需后续阶段复测。
